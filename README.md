# Student Management System

## Project Overview

This project contains a React frontend and a Spring Boot backend. The frontend connects to the backend to access and manage student information.

## Getting Started

### 1. Clone the Repository

Clone the project repository to your local machine and open the project folder.

### 2. Run the Frontend

1. Open the `frontend` folder in VS Code.
2. Open the terminal in the frontend folder.
3. Install the required dependencies:


  - npm install

4. Start the development server:
 
  - npm run dev
 

5. Open the frontend in your browser:

   **http://localhost:5173**

### 3. Run the Backend

1. Open Eclipse.
2. Go to **File → Import → Maven → Existing Maven Projects**.
3. Select the backend project folder and finish the import.
4. Open the main Spring Boot application class in the main package.
5. Right-click the application class and select **Run As → Spring Boot App**.
### 4. Check the Database Configuration
Open `application.properties` in the backend resources folder.

Check that the database connection details are correct:

- Database host and port
- Database name
- Username
- Password

Make sure the database server is running before starting the backend.
### 5. Use the Application
Once the backend and frontend are running, open **http://localhost:5173** in your browser.
